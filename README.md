在线地址（GitHub Pages）：https://evanzhousy.github.io/football-analysis/

## 核心特性
- **直播吧巴萨比赛回放逐帧剪辑同屏**：内置 12 段从直播吧巴萨回放源精剪的佩德里持球摆脱过人 H.264 MP4 + 62 秒 8 大场景连播总集锦，支持与 3D 场景 `0.25x / 0.5x / 1.0x` 倍速与时间轴同步慢放。
- **67 骨骼 Mixamo 蒙皮运动员 + 足踝/手臂/20 指节解析法 IK**：完整还原沉肩虚晃、支撑脚微屈、脚踝内扣/外拨触球与单手护球动作细节，支持一键开启 `X-Ray` 67 骨骼透视与足踝特写机位。
- **CMU 120Hz 光学足球动作捕捉库**：可直接切换播放 120fps 光学动捕 BVH 原片。
- **零构建纯静态架构**：基于原生 ES Modules + `./vendor/three/` 自包含打包，无需任何本地服务器或打包步骤，直接通过 GitHub Pages 在线运行与迭代。
