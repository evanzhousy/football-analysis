## 五层白模原子动作库 × 整场逼抢拆解架构
1. **白模生物力学检阅实验室（White-Model Mannequin Lab）**：默认开启亚光石膏雕塑素体（主角象牙白 `#eef2f6` + 防守灰蓝 `#7c8aa0`）、地面 `1.0m × 1.0m` 标准标定网格与左足（青 `#22d3ee`）/ 右足（橙 `#fb923c`）动态支撑触地环（`Foot-Plant Ring`），一键（快捷键 `[W]`）无缝切换实况球衣与天然割纹草皮模式。
2. **86 组统一 65 骨足球原子动作集合库（`assets/mocap_atomic/*.glb` + `src/soccerAtomicCatalog.js`）**：融合 120Hz Vicon 光学动捕（CMU Subject 78 足球带球急停变向/拉球转身/油炸丸子/马赛回旋/背身半转身/凌空卸球 + 多受试者全速域步态）与 Adobe Mixamo《Soccer Pack》，全库统一重定向至标准 65 骨骼、支持精确矢状面左右镜像（`L/R`）并附带支撑足时序与真实地面速度标定。覆盖 7 大类：
   - `01_stance` 待命与观察扫描（3 组）
   - `02_locomotion` 全速域无球与盘带步态（14 组）
   - `03_first_touch` 第一脚接停与凌空卸球（10 组）
   - `04_turns_pivots` 背身半转身与急停变向（20 组）
   - `05_feints_skills` 假动作虚晃、油炸丸子与马赛回旋（14 组）
   - `06_pass_strike` 传球直塞与抽射挑射（10 组）
   - `07_press_defend_gk` 防守逼抢、滑铲护球与门将扑救（15 组）
3. **C2 惯性连续 Root-Motion 序列组装器（`src/atomicMotionAssembler.js`）**：在每一处原子片段接缝处计算全 65 骨骼角差与角速度，以五次多项式 $h(s) = 1 - s^3(10 - 15s + 6s^2)$ 执行 C2 惯性过渡（Inertialization）与步幅自适应航点对齐，彻底消除接缝突变与原地滑步。
4. **三大场上位置 18 组实况 1:1 复杂动作序列组装（`src/assembledSequences.js`）**：
   - **中场 MF（10 组）**：`#8 佩德里`（01–08 八大标志性摆脱）、`#17 萨乌尔`（09 欧冠半决赛连过拜仁四人破门）、`#7 德布劳内`（10 边线诱敌晃倒双抢 + 38m 外旋穿透长传）。
   - **前锋 FW（4 组）**：`#19 亚马尔`（11 罚球弧顶 1v4 蝴蝶穿花）、`#7 维尼修斯`（12 扛住双卫关门爆趟挑射）、`#11 贝尔`（13 国王杯决赛 36.9km/h 界外弯道超车绝杀）、`#10 巴尔迪`（14 扛人急停内扣晃趴橙衣队长）。
   - **后卫 DF（4 组）**：`#5 范戴克`（15 出球中卫本方半场 70m 一条龙晃飞滑铲破门）、`#12 廷伯`（16 技术型右后卫禁区角背身一脚顺球穿双人缝挑射）、`#19 阿方索·戴维斯`（17 左后卫后场破逼抢 75m 套边胸部卸球助攻）、`#2 阿什拉夫`（18 右翼卫内切连过双腰 28m 重炮世界波）。
5. **整场比赛持球逼抢拆解、自动切片与四维归类工作台（`src/fullMatchWorkspace.js` + `src/fullMatchEngine.js` + `src/fullMatchSamples.js`）**：
   - **三套内置整场真实数据样本（共 124 处持球逼抢切片）**：国家德比 `皇家马德里 2–1 巴塞罗那`（94 分钟 · 56 切片，含 StatsBomb 360° 全员空间定格坐标）、2024 欧洲杯 `西班牙 2–1 德国`（122 分钟加时 · 60 切片）、以及 `巴萨中场实况合集`（8 处原片精确时间戳切片）。
   - **双引擎本地录像自动拆解**：
     - **纯前端无后端切片器**：浏览器直接导入本地比赛 `.mp4/.webm`，基于 Canvas 2D 草皮掩膜 + 攻防球员簇密度峰值自动定位持球受迫时间窗并生成四维归类切片，支持 JSON/CSV 归档导入导出。
     - **离线高精度批处理 CLI（`scripts/analyze_full_match_pressing.py`）**：基于 OpenCV 草皮分割、球员聚类与 Farneback 光流提取整场逼抢事件，支持 `--export-clips` 调用 FFmpeg 批量导出独立 MP4 子切片：
       ```bash
       python scripts/analyze_full_match_pressing.py --video full_match.mp4 --out-dir ./match_slices --export-clips
       ```
   - **四维战术归类交叉检索与 3D 白模一键重演**：按 **逼抢形态与人数**（背身1v1顶防 / 双人关门夹击 / 3人+合围反抢 / 后场高位逼抢）、**球场发生区域**（后场出球区 / 中圈腹地枢纽 / 边路死角陷阱 / 前场肋部与14区）、**摆脱技术与结果**（沉肩半转身 / 油炸丸子·回旋 / 一脚撞墙·直塞 / 护球安全重置 / 被抢断丢球反例）及 **持球位置与焦点球员** 实时联动筛选 `90'/120'` 压迫强度时间轴与 `105m × 68m` 热力/360° 站位图，并支持一键（`🦴 送入 3D 白模实验室重演`）将任意切片（含正面突围与被断反例）动态重构为 65 骨白模 C2 惯性序列！
