## 五层白模原子动作库 × 整场逼抢拆解架构
1. **白模生物力学检阅实验室（White-Model Mannequin Lab）**：默认开启亚光石膏雕塑素体（主角象牙白 `#eef2f6` + 防守灰蓝 `#7c8aa0`）、地面 `1.0m × 1.0m` 标准标定网格与左足（青 `#22d3ee`）/ 右足（橙 `#fb923c`）动态支撑触地环（`Foot-Plant Ring`），一键（快捷键 `[W]`）无缝切换实况球衣与天然割纹草皮模式。
2. **86 组统一 65 骨足球原子动作集合库（`assets/mocap_atomic/*.glb` + `src/soccerAtomicCatalog.js`）**：融合 120Hz Vicon 光学动捕（CMU Subject 78 足球带球急停变向/拉球转身/油炸丸子/马赛回旋/背身半转身/凌空卸球 + 多受试者全速域步态）与 Adobe Mixamo《Soccer Pack》，全库统一重定向至标准 65 骨骼、支持精确矢状面左右镜像（`L/R`）并附带支撑足时序与真实地面速度标定。覆盖 7 大类：
   - `01_stance` 待命与观察扫描（3 组）
   - `02_locomotion` 全速域无球与盘带步态（14 组）
   - `03_first_touch` 第一脚接停与凌空卸球（10 组）
   - `04_turns_pivots` 背身半转身与急停变向（20 组）
   - `05_feints_skills` 假动作虚晃、油炸丸子与马赛回旋（14 组）
   - `06_pass_strike` 传球直塞与抽射挑射（10 组）
   - `07_press_defend_gk` 防守逼抢、滑铲护球与门将扑救（15 组）
3. **C2 惯性连续 Root-Motion 序列组装器（`src/atomicMotionAssembler.js`）**：在每一处原子片段接缝处计算全 65 骨骼角差与角速度，以五次多项式 $h(s) = 1 - s^3(10 - 15s + 6s^2)$ 执行 C2 惯性过渡（Inertialization）与步幅自适应航点对齐，彻底消除接缝突变与原地滑步。
4. **三大场上位置 18 组实况 1:1 复杂动作序列组装（`src/assembledSequences.js`）**：
   - **中场 MF（10 组）**：`#8 佩德里`（01–08 八大标志性摆脱）、`#17 萨乌尔`（09 欧冠半决赛连过拜仁四人破门）、`#7 德布劳内`（10 边线诱敌晃倒双抢 + 38m 外旋穿透长传）。
   - **前锋 FW（4 组）**：`#19 亚马尔`（11 罚球弧顶 1v4 蝴蝶穿花）、`#7 维尼修斯`（12 扛住双卫关门爆趟挑射）、`#11 贝尔`（13 国王杯决赛 36.9km/h 界外弯道超车绝杀）、`#10 巴尔迪`（14 扛人急停内扣晃趴橙衣队长）。
   - **后卫 DF（4 组）**：`#5 范戴克`（15 出球中卫本方半场 70m 一条龙晃飞滑铲破门）、`#12 廷伯`（16 技术型右后卫禁区角背身一脚顺球穿双人缝挑射）、`#19 阿方索·戴维斯`（17 左后卫后场破逼抢 75m 套边胸部卸球助攻）、`#2 阿什拉夫`（18 右翼卫内切连过双腰 28m 重炮世界波）。
5. **整场比赛持球逼抢拆解、战术诊断与四维切片工作台（`src/fullMatchWorkspace.js` + `src/fullMatchEngine.js` + `src/fullMatchSamples.js`）**：
   - **三套内置整场真实数据样本（共 124 处持球逼抢切片）**：国家德比 `皇家马德里 2–1 巴塞罗那`（94 分钟 · 56 切片，含 StatsBomb 360° 全员空间定格坐标）、2024 欧洲杯 `西班牙 2–1 德国`（122 分钟加时 · 60 切片，主客色轨与时间轴严格对齐）、以及 `巴萨中场实况合集`（8 处原片精确时间戳切片）。
   - **主客双队双轨时间轴（支持拖拽框选区间） & 3 模态中心分析舞台**：
     - **`🗺️ 热区&分区`**：`105m × 68m` FIFA 球场热力向量图 + 4 大战术分区**可点击实况破围率 HUD**（点击任意分区直接筛选）。
     - **`🎯 360°压迫遮蔽`**：默认 **`🔍 局部特写 2.2x`** 跟随持球人居中放大（支持一键切换全览 `1.0x`），叠加 `5m` 标定网格、`2.5m` 贴防高压圈与 `5.0m` 合拢圈、`D1`/`D2` 逼抢人合围箭头与精确贴防距、防守者 **Cover-Shadow 遮蔽锥**、队友 **`开放 X.Xm` / `遮蔽 ✕`** 传球通道徽标，以及 **`📸 导图`** 一键导出高清 PNG 战术简报图。
     - **`📊 全场诊断&矩阵`**：进入诊断模式自动切换紧凑底舱（可一键 `🎬 展开视频舱`），一屏零截断呈现 4 条自动教练洞察、主客双队抗压对抗镜面柱图、**可点击筛选的 15 分钟压迫潮汐波峰**、**可点击 `逼抢形态 × 摆脱结果` 二维交叉矩阵**与 **Top-7 球员抗压排行榜**。
   - **教练级视频剪辑工作室（Video Cut-Up Studio）与离线/前端双引擎**：
     - **纯前端两阶段扫描（含自动双队球衣聚类）+ 录像绑定校准**：扫前配置主客队名、时间范围与采样精度（`0.5s`/`1.0s`/`2.0s`），采用 **6 桶异色球衣对抗度（Dual-Team Chromatic Contrast）** 过滤同队扎堆并自动将检测切片按主/客优势球衣色簇归队；同时支持为内置数据或导入 JSON **绑定任意本地整场 MP4** 并做 `±5s` 开球偏移校准。
     - **完整切片编辑与剪辑包流**：支持 **`★ 精选剪辑包`** 收藏筛选（快捷键 `S`）、球衣号码 `#` 与球员名行内即时编辑、**连播剪辑单（Cut-Up Playlist）**、`0.5x/1.0x` 慢镜、起止时间微调（`±0.5s`）、实时打点新增切片（自动截当前视频帧缩略图）、自定义战术备注、删除切片与 `localStorage` 自动持久化；支持导出 **JSON / CSV / Markdown 教练战术报告**、**`🎞 剪辑脚本` 一键生成本地无损 FFmpeg `.sh` 集锦裁剪脚本**，以及一键（`🦴 送入 3D 实验室重演`）重构为 65 骨白模 C2 惯性序列。
     - **离线高精度批处理 CLI（`scripts/analyze_full_match_pressing.py`）**：基于 OpenCV 草皮分割、异色球衣对抗评分与运动流批量提取整场切片，自动输出内嵌 Base64 缩略图的 `match_pressing_breakdown.json`、配套 `.csv` 与 `.md` 报告，支持 `--export-clips` 调用 FFmpeg 导出独立 MP4 子切片：
       ```bash
       python scripts/analyze_full_match_pressing.py --video full_match.mp4 --out-dir ./match_slices --export-clips
       ```
